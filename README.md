# Calculator

A simple browser calculator built with plain HTML, CSS, and JavaScript.

![Calculator screenshot](Calculator%20Screenshot%202026-09-09%20002827.png)

## Features

- Addition, subtraction, multiplication, and division
- Decimal input and a clear (C) button
- Chained operations, evaluated left to right as each operator is pressed
- "Error: Division by zero" message instead of a crash
- Keyboard support
- Dark theme by default, with a toggle button for light mode

## Keyboard shortcuts

| Key | Action |
| --- | --- |
| `0`–`9` | Enter digit |
| `.` | Decimal point |
| `+` `-` `*` `/` | Operators |
| `Enter` or `=` | Calculate |
| `Esc` | Clear |

## Run

No build or dependencies needed. Open `index.html` in a browser.

## Tech

- `index.html`: layout
- `style.css`: styling and themes
- `script.js`: calculator logic, keyboard handling, theme toggle
